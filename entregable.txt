¿Para qué funciona un keyframe?
Para tener el control de la secuencia de las animaciones de forma más específica

Explica 3 propiedades de las animaciones que seleccionaste
transform-origin: Las transformaciones 2D pueden cambiar el eje x e y de un elemento. En caso de haber elementos 3D, el eje z también puede cambiar
transform: aplica una transformación 2D o 3D a un elemento. Esta propiedad le permite rotar, escalar, mover, sesgar, etc., elementos
@keyframes: es la regla especifica el código de animación. La animación se crea cambiando gradualmente de un conjunto de estilos CSS a otro
